# Data provenance and attribution

The menu observations originate from [Edmund Goodman’s jacks-menu-history](https://github.com/EdmundGoodman/jacks-menu-history), pinned at commit `fba48c936c059625f399353e5afa8b071fc51457`. Its README identifies it as an artifact store for menus collected by [jacks-menu](https://github.com/EdmundGoodman/jacks-menu).

This project is an independent analysis of Jack’s Gelato menu records and is not an official shop service. Credit for collection belongs to the upstream project; the prediction models and descriptive analyses are developed here.

Included processed history covers 4 October 2024–17 October 2026. Of 1,417 source records, 1,222 pass the usability audit and 195 are quarantined; 71 expected shop/date records are missing. `data/processed/` contains the audited tables and exclusion details. Raw source files and upstream Git history are not bundled.

The frozen manifests record source/configuration/data/model checksums. Flavour matching is deliberately conservative; naming variants can remain distinct. Missing records are unknown, never negative labels. Historical data availability is assumed rather than timestamp-verified.

No license file was present in the pinned upstream checkout. This repository does not grant or imply a new license over third-party source material. Attribution records provenance; it does not change upstream rights.
